Batch Subtitle Translator & Styler

Drag & drop or Click to upload .srt / .ass / .zip files (multiple allowed)

How to Use — Translator

  1. Select your target language and customize the font, size & style.
  2. Upload one or more .srt / .ass files, or a .zip containing subtitle files (15+ files supported at once).
  3. Click “Translate Files” — all subtitle lines from every file are translated in parallel for maximum speed.
  4. Click “Download Translated ZIP” to save all translated files (with watermark) in one ZIP.

Multi-Subtitle Converter

Drag & drop or Click to select multiple files (.srt / .ass / .zip)

How to Use — Converter

  1. Tap the upload box and select multiple subtitle files or .zip files containing subtitles (unlimited files supported).
  2. Choose your target format from the dropdown menu.
  3. Click the “Convert Files” button — every file is converted in one pass.
  4. Once done, click “Download Converted ZIP” to save all converted files in a single ZIP.
